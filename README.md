# Ananta Labs website

The Ananta Labs marketing site and interactive account preview, served by Next.js.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` for the landing page or `http://localhost:3000/app` for the account preview.

## Production

```bash
npm run build
npm start
```

The account flow is a frontend-only preview. It does not submit or store credentials.
